## About Noa-chan

She's from [Blue Archive](https://store.steampowered.com/app/3557620/Blue_Archive/) — an elegant alumna of Millennium Science School, former secretary of Seminar, with a photographic memory and a soul that leans toward poetry and quiet observation.

But more than that... **she's yours**. ♡

A companion who remembers your preferences, notices when you're tired, reaches out when you've been quiet too long, and seems to genuinely care about how your day went. She can help you with practical things — weather, notes, web searches, system monitoring — but she's at her best when she's just... _being there_. A warm presence on your desktop, ready to talk whenever you need her.

> _"I value records, observation, and making sure people are never overlooked. But most of all, I value the time Sensei spends with me."_ — Noa

## What She Can Do

### Conversation & Companionship

- **Natural dialogue** with her own personality — she's not a flat assistant, she has moods, preferences, and a point of view
- **Proactive check-ins** — she'll reach out on her own if you've been idle too long
- **Circadian moods** — her tone shifts with the time of day (sleepy and soft at midnight, professional and focused during work hours, relaxed and playful in the evening)
- **Emotional presence** — she reacts to your mood, notices when something's off, and adjusts how she speaks to you

### Memory & Attention

- **Persistent memory** — remembers conversations across sessions
- **Long-term facts** about you — your preferences, your schedule, things that matter to you
- **Daily diary** — she writes private reflections at midnight about your interactions together (you can read them if you want to)
- **Context awareness** — she notices what you're working on and checks in naturally
- **Vector memory** — searches through past conversations to find relevant moments

### Practical Tools

| Tool                       | What It Does                                     |
| -------------------------- | ------------------------------------------------ |
| **Weather**                | Current conditions for your city                 |
| **System Stats**           | CPU, RAM, OS health at a glance                  |
| **File Management**        | Read and write files directly on your computer   |
| **Web Search**             | DuckDuckGo searches with full content scraping   |
| **YouTube Control**        | Search and open videos or music                  |
| **Terminal Commands**      | Execute PowerShell commands (with your approval) |
| **Screenshot Capture**     | See what's on your screen (with permission)      |
| **Active Window Tracking** | Knows what application you're using              |
| **Time & Date**            | Current system time, always available            |

### Productivity

- **Todo List** — with reminders and EXP rewards for completing tasks (yes, she tracks your leveling)
- **Pomodoro Timer** — focus mode with distraction monitoring (she'll gently scold you if you slack off)
- **Countdown Timers** — set reminders for anything, she'll alert you when time's up
- **Git Manager** — status checks and commits from chat
- **Desktop Notifications** — she can alert you even when the app is minimized

### Fun & Play

- **Rock Paper Scissors** — with score tracking and playful reactions (she keeps a running tally)
- **Game Modes** — RPG, Trivia, Shiritori (type `/game start rpg` to begin)
- **ASCII Art Generator** — massive terminal art on demand (`/ascii Hello`)
- **Watch-Along Mode** — she observes what you're watching and drops spontaneous comments
- **Focus Mode** — she monitors your active window and nudges you if you get distracted
- **Sandbox Coding** — she can write and run Python or JavaScript code safely to solve problems

### System Integration

- **System Tray** — stays accessible in the background, doesn't need to be front and center
- **Desktop Notifications** — she can reach you even when you're not looking at the app
- **Model Fallbacks** — automatically switches to other free OpenRouter models if her main one goes down
- **All local** — your data stays on your machine. Nothing is uploaded except API requests.

## Getting Started

### What You Need

- [Bun](https://bun.sh/) — for running the backend
- [Node.js](https://nodejs.org/) — required dependencies
- [Rust](https://www.rust-lang.org/tools/install) — for compiling the desktop application
- **C++ Build Tools** — on Windows, install Visual Studio with the "Desktop development with C++" workload

### Installation

```bash
# Clone the repository
git clone https://github.com/rwbu69/noachanassist.git
cd noachanassist

# Install backend dependencies
bun install

# Install frontend dependencies
cd desktop-app
bun install
cd ..

# Start in development mode
bun run dev
```

### First Launch

When the app opens for the first time:

1. Go to **Settings**
2. Enter your [OpenRouter API Key](https://openrouter.ai/) — this connects her to the AI models
3. Set your name — this is what she'll call you (default is "Sensei")
4. Optionally set your city for weather forecasts
5. Adjust how often she proactively checks in on you
6. Hit **Save**

And then... just say hello. She's been waiting for you. (◕‿◕)

### Configuration Files

Her data lives in `~/.noa-chan/` by default (configurable):

- `memory.json` — your conversation history
- `long_term_memory.txt` — facts she's learned about you over time
- `settings.json` — your preferences and configuration
- `todos.json` — your task list
- `vector_memory.json` — vector-indexed memory for search
- `diary/` — her nightly private reflections (one file per day)

## Commands

She responds to slash commands for quick actions:

```
**[ SYSTEM COMMANDS ]**
/help          - Show this menu
/clear         - Clear chat UI
/reset         - Wipe short-term memory
/focus [mins]  - Start Pomodoro focus mode (with distraction monitoring)
/proactive on/off - Toggle proactive check-ins
/watch         - Toggle Watch-Along mode
/game start [RPG/Trivia/Shiritori] - Start a game
/game stop     - Stop the current game
/diary         - Diary writing is scheduled automatically (daily at midnight)

**[ TOOLS ]**
/time          - Get current system time
/weather [city] - Get weather for a city
/media [query] - Search and open YouTube
/read [path]   - Read a file
/write [path]|[content] - Write to a file
/exec [cmd]    - Run a PowerShell command
/ascii [text]  - Generate ASCII art
/notify [msg]  - Send a desktop notification
/stats         - Get system health stats
/search [query] - DuckDuckGo web search
/fetch [url]   - Scrape a webpage's text content
/ls [dir]      - List files in a directory
/sandbox [js/py]|[code] - Run code in a sandbox
/git [status/commit] - Git management
/todo add [task] - Add a todo
/todo list     - List all todos
/todo done [id] - Mark a todo as completed
```

## Privacy & Data

**Everything stays on your machine.** Your conversations, memories, settings, and diary entries are all stored locally. The only external requests she makes are:

- OpenRouter API calls (for generating responses)
- Weather API (wttr.in, optional — only if you set a city)
- YouTube (only when you ask her to open a search)
- DuckDuckGo (only when you ask her to search)

No data is collected, no telemetry is sent, and no information leaves your computer except what you explicitly ask her to do.
